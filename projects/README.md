## Project 1: Harvest Table Restaurant – Static Website

A fully functional static website for a local restaurant to enable online booking, meal ordering, and admin management. The project replaces a manual paper-based system with a cloud-native solution hosted on Amazon S3, allowing customers to browse the menu, book tables, place orders, and receive instant confirmations. The restaurant owner can log in to an admin dashboard to view and manage bookings and orders.

**Key Features:**
- Online booking and ordering system
- Admin dashboard for managing bookings and orders
- Proposed integration with AWS Cognito, DynamoDB, Lambda, and SNS
- Over 95% cost reduction compared to manual system

---

## Project 2: ID-Please – Cognito Mastery Quiz Bot

An interactive, authentication-focused chatbot built using Amazon Lex for CloudLearners Inc. The bot educates users on Amazon Cognito through an engaging quiz experience, covering key concepts like User Pools, Identity Pools, token types, multi-factor authentication, and password reset flows. The bot provides instant feedback, educational explanations, and fun facts to reinforce learning.

**Key Features:**
- 7 intents and 5 slots for structured quiz flow
- Conditional branching for correct/incorrect feedback
- Educational content with fun facts
- Built by Bot Solutions team
