# ☁️ 3 Months on AWS – My Cloud Learning Plan

## Who I Am

I am Owen Maake. An NQF Level 4 IT graduate. A SOC analyst in training. A home lab builder. Someone who refuses to stay still.

I built a Kali Linux SOC lab to practice threat detection. I completed TryHackMe SOC Level 1 training. I hold AWS AI Practitioner and Microsoft Azure Fundamentals.

Now I am adding cloud to my skills.

---

## Why AWS?

Most SOC analysts know firewalls and endpoints. Few understand cloud.

I want to be the analyst who can investigate threats anywhere. Traditional networks. Cloud environments. Hybrid setups.

AWS is where I start.

---

## What I Will Do for the Next 3 Months

This is not a wishlist. This is my plan.

### Month 1 – Foundations and Compute

| Week | Focus | What I Will Build |
|------|-------|--------------------|
| Week 1 | Cloud concepts + Global infrastructure | Study notes, quiz myself |
| Week 2 | EC2 fundamentals | Launch, connect, stop, terminate |
| Week 3 | Security groups + Key pairs | Test different security group rules |
| Week 4 | Auto Scaling + Load Balancers | Build a simple web server that scales |

### Month 2 – Networking, Storage, and Databases

| Week | Focus | What I Will Build |
|------|-------|--------------------|
| Week 5 | VPC + Subnets + Route tables | Build my own VPC from scratch |
| Week 6 | Internet Gateway + NAT Gateway | Public vs private subnets |
| Week 7 | S3 storage | Create buckets, set permissions, host a static site |
| Week 8 | RDS databases | Launch MySQL, connect, run queries |

### Month 3 – Security, Monitoring, and Integration

| Week | Focus | What I Will Build |
|------|-------|--------------------|
| Week 9 | IAM (users, groups, roles, policies) | Create users with least privilege |
| Week 10 | CloudTrail + CloudWatch | Log analysis practice |
| Week 11 | Combine everything | Small project using EC2 + VPC + S3 + IAM |
| Week 12 | Cloud Practitioner exam prep | Practice exams, weak topic review |

---

## How I Will Document Everything

For each thing I build, I will ask myself three questions:

1. What did I build?
2. What went wrong?
3. What did I learn?

I will write the answers in this repository.

No copy-paste. No fake notes. Just my real experience.
