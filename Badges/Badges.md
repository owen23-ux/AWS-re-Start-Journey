## What I Built

**Compute**
- Launched EC2 instances
- Configured Auto Scaling groups
- Set up Application Load Balancers

**Storage**
- Created S3 buckets with proper permissions
- Configured versioning and lifecycle policies
- Understood storage classes (Standard, Glacier, etc.)

**Networking**
- Built VPCs from scratch
- Created public and private subnets
- Configured route tables and Internet Gateways

**Databases**
- Launched RDS (MySQL)
- Understood DynamoDB basics
- Practiced backups and snapshots

**Security**
- Created IAM users, groups, and roles
- Applied least privilege policies
- Understood Security Groups vs NACLs
- Learned the Shared Responsibility Model

**Serverless**
- Created Lambda functions
- Used API Gateway
- Combined Lambda with S3 events

**Monitoring**
- Set up CloudWatch alarms
- Viewed CloudTrail logs
- Configured basic dashboards

## What I Learned About Learning

I tried memorising AWS services. That did not work.

What worked was building something, watching it fail, and figuring out why.

Cloud Quest forced me to do exactly that.
