# Labs

Hands-on lab exercises completed throughout the AWS re/Start curriculum, organized by domain.

| Folder | Focus |
|---|---|
| [compute/](./compute/) | EC2, Lambda, serverless, scaling |
| [networking/](./networking/) | VPCs, subnets, routing, security groups |
| [security/](./security/) | IAM, CloudWatch, GuardDuty, Inspector, hardening |
| [databases/](./databases/) | RDS, SQL queries, conditional search |
| [storage/](./storage/) | S3 hosting, versioning, EFS file systems |
| [python/](./python/) | Automation scripts, file handling, ciphers |

---

## Compute
- **EC2 Basics:** Launching, connecting, and securing virtual servers
- **Lambda:** Serverless compute and event-driven functions

## Networking
- **VPC Design:** Creating isolated networks with public and private subnets
- **Security Groups & NACLs:** Understanding stateful vs. stateless firewalls
- **Route Tables:** Configuring traffic routing between subnets and the internet

## Security
- **IAM:** Managing users, groups, roles, and policies
- **CloudWatch:** Monitoring infrastructure and setting alarms
- **Network Firewall & Inspector:** Malware protection and vulnerability scanning
- **Systems Manager:** Patch management and security hardening

## Databases
- **RDS:** Deploying and managing relational databases
- **SQL Queries:** Conditional search, SELECT/INSERT/JOIN operations

## Storage
- **S3:** Static website hosting and object versioning
- **EFS:** Elastic file systems across availability zones

## Python
- **Automation:** File handling, JSON modules, Caesar cipher functions
